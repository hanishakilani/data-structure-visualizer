### Data Structure Visualizer

A Python GUI application built using Tkinter to visualize basic data structures like:
Singly Linked List
Stack
Queue
This project helps beginners understand how data structures work through interactive graphical visualization. 

## Features
# Linked List
Insert at Head
Insert at Tail
Delete Node
Visual representation with arrows
Highlight animation for inserted nodes

# Stack
Push elements
Pop elements
Peek top element
Stack visualization from bottom to top

# Queue
Enqueue elements
Dequeue elements
View Front element
Front and Rear indicators

## Technologies Used

## Installation
1. Clone the Repository
git clone https://github.com/hanishakilani/data-structure-visualizer.git
2. Navigate to the Project Folder
cd data-structure-visualizer
3. Run the Program
python main.py

## Requirements
Python 3.x
Tkinter usually comes pre-installed with Python.
To verify:
python -m tkinter
